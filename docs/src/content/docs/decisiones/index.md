Algunas decisiones del proyecto vinieron de una investigación previa (un
"spike"): comparar opciones, revisar fuentes oficiales y recomendar un
camino antes de implementar. Esos documentos completos viven como Markdown
suelto en el repositorio, en `docs/`; acá hay un resumen de cada uno con el
link a la fuente completa.

- [Google Reseñas](/qr-generator/decisiones/google-resenas/) — por qué el QR
  se genera a partir de un Place ID pegado a mano, y no de cualquier link de
  Maps.
- [Mercado Pago](/qr-generator/decisiones/mercado-pago/) — comparación de
  opciones para cobrar con QR; todavía no implementado (la app muestra
  **Próximamente**).
- [Impresión directa](/qr-generator/decisiones/impresion-directa/) — spike de
  impresión por Bluetooth desde iOS a la DT01, sin pasar por WePrint.
