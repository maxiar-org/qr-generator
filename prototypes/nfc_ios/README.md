# Prueba NFC para iOS

Prototipo del issue #35, apagado por defecto. Destino nativo único: iOS.

Requiere una cuenta paga del Apple Developer Program para compilar: la
capability "Near Field Communication Tag Reading" no está disponible con un
Personal Team gratuito. Detalle, entitlements y prueba física con el iPhone
de Maxi: [spike de NFC](../../docs/spike-nfc.md).
